## Decision

Keep **Mass Society As Political Constraint** whole for now, but put it on compression-watch. Do not reopen a child split before the next ordinary public edit.

The page has reached the source-count diagnostic: direct authored metrics on current `main` are about 4,972 words, 66 authored `evidence=` attributes, 70 unique authored video segment refs, 20 distinct authored local video slugs, and 14 lens points. That is real split pressure, but it is not yet proof of a child boundary. The current public page already separates the administrative-control material into compact reader surfaces: **Digital Permission Grids**, **Domestic Control Becomes A War Grid**, **Ruin Becomes Administrative Terrain**, **Scarcity Turns Control Martial**, and **Population Management Becomes War**.

The first future child test remains **Digital Permission / Administrative Control Grid**, not a generic AI-police-state, digital-ID, data-center, China, Palantir, draft, or child-safety page.

Those anchors already give episode marks and public hovers narrower handles inside the parent. A child page would help only if those handles stop being enough for reader navigation.

The prior control-grid reviews were correct to hold the child: the current public page carries the mechanism compactly rather than merely accumulating examples. Since then, the page has gained source fan-in, but the active mechanism has not changed. Mass Society still owns the population-administration layer: identity, programmable money, apps, purchase/location records, databases, data centers, AI sign-off, policing, draft administration, rationing, embodied data, and safety consent as a system for granting, delaying, freezing, monitoring, or denying ordinary action.

## Reopen Condition

Reopen **Digital Permission / Administrative Control Grid** as a child only if at least one of these conditions becomes true:

1. The next necessary public edit would push the Mass Society parent above roughly 6,000 authored words after replacement/compression has been tried.
2. Episode read marks or generated backlinks cluster around `mass-society-digital-permission-grid`, `mass-society-embodied-data-grid`, and `mass-society-domestic-war-control-grid` so heavily that one parent hover no longer helps readers distinguish the administrative bundle.
3. Four or more additional dated sources repeat the whole administrative-control bundle rather than one component, making the parent section unreadable as a compact sequence.
4. A Prediction or ledger review needs a stable public explanation of the administrative apparatus and cannot cite existing Mass Society anchors without turning the forecast itself into an unfalsifiable police-state bundle.
5. Dante review of a replacement/compression draft says the page remains too dense and names digital permission / administrative control as the first child boundary.

If none of those conditions holds, the next visible Mass Society edit should replace or compress existing public prose rather than add another ordinary surveillance example or create a child page.
