## Routing Rules

Use **Eschatology** when the active mechanism is sacred role assignment, final order, promise becoming plan, ritual sequence, Antichrist function, messianic age, holy empire, or catastrophe made meaningful as obedience to the end.

Use **Prediction** when the active object is source date, horizon, exact forecast branch, later comparison, confirmation status, or ledger readiness. The August 1 lecture's Iran, Odessa/NATO, Turkey/Byzantium, Israel/Third Temple, Putin succession, China absence, and Anglo-American retreat sequence should stay split into forecast families.

Use **Chokepoint** or **Iran As Pressure Point** when the active object is Hormuz, water, blockade, energy, naval access, ground-invasion cost, pressure hardening, or no-exit material war.

Use **Secret Society** when the active object is hidden trust, initiation, taboo, blackmail, covert coordination, or secrecy-bound elite machinery. Do not route the whole eschatological script there just because the source contrasts conspiracy with script coordination.

Use **Gerontocracy** when the active object is shortened elite time horizon: aging rulers declining to answer a hostile long plan because the bill arrives after their expected deaths.

Use **AI As Control Surface**, **Mass Society**, **Attention**, and **Power As Alchemy** for AI-related pressure by active mechanism: interface and command surface; population administration; captured consciousness; or value conversion from money to AI.

Use **Free Will** and **Human Heart** when the active object is noncoercive agency, love, refusal, redemption, or the claim that salvation cannot be achieved by removing choice.
