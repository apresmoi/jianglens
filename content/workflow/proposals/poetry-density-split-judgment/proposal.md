Date: 2026-07-02

## Decision

Freeze **How Poetry Creates Civilization** for ordinary source appends. The page should stay the public parent for the general mechanism, but the next visible Poetry mutation should reopen the narrow **Dante As Poetic Access And Reception** child path and pair it with parent compression.

This is a change from the July 1 split plan's "compression first, child only if compression fails" posture. Compression has now been tried: PR #1170 compressed the Dante reception layer while preserving the parent. The direct authored page count is about 5,347 words, so the page is below the ordinary 6,000-word warning line. The reopen pressure instead comes from density and concentration: 114 raw evidence attributes, 15 distinct authored local video slugs, 9 stable anchors, 105 compiled doc evidence marks, 94 unique compiled segment refs, 32 episode links mentioning Poetry anchors, and a Dante access/reception branch that kept accumulating after compression. Dante access, invasion, delayed reception, memory software, prophecy as present critique, and Purgatory beginning by washing Virgil off are now doing more work than a parent section should keep absorbing.

Do not create a generic Dante page, Paradiso page, Inferno page, Purgatory page, Virgil page, Jesus portal page, Shakespeare page, Homer page, Modernism page, Oral Memory page, or Hollywood page from this pressure. The only child worth reopening is the reception mechanism already named in the July 1 plan: how Dante's poem opens access by entering memory before full understanding, democratizing contact with truth, surviving exile and delayed readers, and later unlocking itself through imagination, love, catastrophe, and practice.

## Why This Advances The Lens Map

This run answers a direct Socrates request rather than historical corpus-impact backfill. The default budget-mode audit reports no fresh missing corpus-impact items, and historical backfill remains paused. Cassandra's corrected warning named `how-poetry-creates-civilization.md`; Socrates then asked for a bounded stay-whole versus child-reopen decision before more public edits land.

The decision protects the atlas from two failures. The first failure is topic sprawl: every Dante canto, Homer scene, Shakespeare lecture, or religious comparison could become its own page. The second failure is parent overload: Poetry is now doing parent definition, Homer origin, oral-memory medium, tragedy, poet-prophet access, Dante reception, modernism, Shakespeare language empire, Hollywood bridge, and chronology. A reader can still hold the parent mechanism, but another Dante append would make the parent less useful.

The right boundary is not "Dante" as an author or corpus topic. The boundary is **poetic access and reception**: a poem becomes civilizational when it enters memory, creates dissonance, waits for later experience, lets ordinary readers bypass elite mediation, and turns delayed recognition into a mode of truth. That mechanism is narrower than Poetry as a whole and different from the neighboring Dante routes.

## Parent Boundary After Reopen

Keep **How Poetry Creates Civilization** as the parent when the active mechanism is:

1. language turns private perception into a shared world;
2. rhythm, memory, performance, image, metaphor, or character makes that world inhabitable;
3. poetic form creates civilization-scale access to meaning, morality, and metaphysics;
4. the same power can liberate, infect, democratize, privatize, imperialize, or trap the soul;
5. a source is needed to explain why poetry as such is infrastructure, not merely an example from one author.

After child extraction, the parent should keep a compact Dante bridge because Dante remains one of the central examples of poetic world-making. It should not keep the full June 2026 reception trail, multiple delayed-reader formulations, or every guide/agency/love route that belongs to neighboring concepts.
