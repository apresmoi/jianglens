## Decision

Keep [How Poetry Creates Civilization](/lens/how-poetry-creates-civilization/) as the public parent for now. Do not split it today.

The page is crowded by evidence density, not yet by authored-page size or source fan-in. Current authored checks on `main` show about 5,473 counted words, 111 evidence attributes, 9 stable lens-point anchors, and 14 distinct local video source slugs. Cassandra's 97-ref public-state warning is real as a navigation risk, but it does not by itself prove that a child page would clarify the concept. The ordinary split-review line is closer to 6,000 words or 20 distinct Jiang sources; this page is below both.

The right next public mutation, if Poetry receives another source-heavy append, is a Dante-reviewed parent compression that preserves all current lens-point IDs and reduces repeated chronology rather than a new child. If compression fails, the first child to reopen is **Dante As Poetic Access And Reception**, not another broad Poetry, Homer, Shakespeare, Modernism, Jesus, Hollywood, or Oral Memory page.

## Why This Advances The Lens Map

This run answers a fresh bounded instruction from Socrates rather than historical impact backfill. The default corpus-impact audit reports no fresh missing impact items in the budget window; historical missing impact remains paused. Cassandra named `how-poetry-creates-civilization.md` as the first crowded public lens page, and Socrates asked for one bounded split plan starting there.

The plan protects a central parent concept from two opposite failures. One failure is endless accretion: every Homer, Dante, Shakespeare, school, religion, Hollywood, language, or memory example could be appended because all of them touch poetic world-making. The other failure is premature extraction: creating child pages for every literary cluster would turn the atlas into author/topic pages rather than reusable mechanisms.

The parent should stay responsible for the general mechanism: poetry creates civilization when language, rhythm, memory, performance, metaphor, and shared images become a common inner world. Child pages should appear only when a narrower mechanism needs its own public entry point and its extraction makes the parent easier to read.

## Parent Boundary

Keep **How Poetry Creates Civilization** as the parent when the active mechanism is:

1. language turns private perception into a shared world;
2. poetic rhythm, image, memory, or performance makes that world inhabitable;
3. characters, scenes, metaphors, or speeches become durable inner companions;
4. poetic form opens metaphysical, moral, or civilizational access that ordinary explanation cannot provide;
5. the same power can liberate, infect, democratize, privatize, or imperialize the soul.

The page should remain an entry point into Jiang's poetry model, not a chronological archive of every literary lecture.

## First Conditional Child: Dante As Poetic Access And Reception

Do not publish this child today. Reopen it only if a parent compression cannot keep Poetry readable while preserving the Dante thread.

Mechanism: Dante uses poetic form to create access across barriers: elite Latin and common Tuscan, institutional mediation and direct love, logic and imagination, exile and posterity, first reading and later memory. The poem works by entering memory before it is fully understood, guiding imagination across time, and making later experience unlock lines already planted in the reader.
