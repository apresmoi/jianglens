## Split Or Merge Judgment

Do **not** create a Money Alchemy child now.

The money section is the concentrated branch, but a generic money child would duplicate the parent mechanism and collide with Dollar Hegemony and Debt As Sovereignty. The current section already routes repeated dollar and debt machinery outward. If future pressure forces a child, the child should not be "money" broadly. It should be a narrower replacement-compression artifact that preserves only what Power uniquely owns: monetary signs becoming lived reality before the dollar/debt system machinery takes over.

Do **not** create a Nation-State Memory child now.

The national-memory branch has two sources and two anchors. It is essential to the parent because it proves Power is not merely a money page. But it does not yet have enough independent source fan-in to become a mature child. Nation As God-Machine is the better public neighbor once the installed memory has become population, war, and sacred body.

Do **not** create a Monotheism As Abstraction Engine child now.

The monotheism section is a seed-bearing bridge, not a page-ready concept. Existing workflow memory already holds Monotheism As Abstraction Engine as a seed until the Secret History religion cluster is compared. Power should keep the abstraction-conversion spine, while Religion, Eschatology, Dead World, Free Will, Legitimacy Fiction, and Reason As Replacement Religion own the surrounding mechanisms.

Do **not** create a Capital Safe House or Pax Judaica child now.

The capital-migration branch is already narrow enough on Power through `power-alchemy-capital-migrates-to-enforcement`, and the June 14 review held Pax Judaica As Capital Safe House as a Power-owned seed rather than a public page. Imperial Retrenchment owns host-selection burden; Eschatology owns sacred sequence; AI Control and Mass Society own surveillance machinery; Prediction owns dated scoring.

Do **not** merge Power into Stories, Attention, Nation, Religion, or Dead World.

Those pages explain adjacent machines. Power owns the prior conversion by which an abstraction becomes the reality inside which those machines can work. Merging it away would blur one of the root lens mechanisms.
