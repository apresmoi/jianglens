# Glossary Coverage Backlog

The glossary should become a curated search and agent entry layer, not a mirror
of every generated topic alias. Target 50-100 entries from terms that have:

- clear search or agent intent,
- repeated source support,
- a stable one-paragraph definition,
- a useful route into deeper lens pages,
- exact source refs for "where did Jiang say this?" answers.

## Rule

Do not create glossary entries only because a topic route exists. Use topic
routes as source packets; the glossary page must still answer a real reader or
agent query quickly and point back to dated source evidence.
