# Game Theory Split Review

Status: proposal for public lens size governance

## Decision

Treat [Game Theory](/lens/game-theory/) as a split-review candidate before adding another ordinary subsection. The page is now about 6,159 words, carries 22 distinct source refs, and already has 11 durable lens points. It remains a strong reader entry point, but it is beginning to hold several different mechanisms under one method-name: player/payoff diagnosis, proximity games, proxy-player identification, host-written rules, coordination technology, target-order alignment, prediction discipline, and non-material rewards.

The next public mutation should preserve Game Theory as the parent method page while testing one or two child-boundary candidates. Do not append more Iran-war, elite-faction, grand-bargain, or proxy-war material to the parent unless the edit compresses an existing section or moves a cluster toward a child page.

## Why This Advances The Lens

The live corpus is routing more material to Game Theory than the public page can absorb without becoming a catchall. Recent corpus-impact records already send domestic elite conflict, third-term/emergency-power forecasts, strategic sequencing, grand-bargain bargaining, and no-successor chaos toward Game Theory or its neighbors. Without a split review, future agents will keep adding correct but structurally expensive examples to a page whose real job is to teach the method.

This is synthesis work after repeated compact impact intakes. It turns accumulated routing pressure into a map decision: the question is no longer whether Game Theory is important, but which repeated mechanisms deserve parent, child, or neighboring-page treatment.

## Recommended Parent Boundary

Keep the parent page as **Jiang's method for finding the real game**:

1. name the players;
2. name the rules and constraints;
3. identify the actual payoff;
4. ask which game is nearest to the actor;
5. test whether the declared story survives player psychology, coordination, and material constraints.

The parent should hold the method, its diagnostic questions, and the short examples needed to teach the method. It should not become the full home for every domestic, geopolitical, financial, spiritual, or educational game that the method can analyze.
