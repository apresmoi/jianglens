## Boundary Decision

Keep Chokepoint whole for now:

> A weakening empire turns circulation into access control, then finds that the gates it controls can trap it inside wars it cannot cheaply end.

That boundary still fits the current page. The soft pressure comes from density, not conceptual fracture. A split today would either duplicate the Chokepoint page or create thin children that need the parent to explain them.

Use **Chokepoint** when the active object is a material gate: strait, canal, sea lane, port, island chain, base network, blockade, naval attrition, ground-war trap, energy/food route, or the exit cost created by protection credibility.

Use **Prediction** when the active object is source date, horizon, condition, forecast comparison, miss, revision, or ledger readiness. The Iran-war cluster now needs forecast-family discipline more than another Chokepoint paragraph.
