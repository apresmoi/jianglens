## Split Threshold

Create a child page only if at least one of these conditions appears:

1. The Mass Society parent crosses roughly 6,000 words again and the next necessary edit cannot replace or compress existing control-grid prose.
2. Episode read marks cluster around digital permission / administrative control and need a narrower hover than the existing Mass Society anchors can provide.
3. Future corpus-impact records add new dated sources that repeat the whole control-grid bundle rather than one component, making the parent section unreadable as a compact sequence.
4. A Prediction or ledger promotion needs a stable public explanation of the administrative apparatus without making the forecast itself unfalsifiable.
5. A Dante review says the parent page is still too dense after replacement/compression and identifies the digital-permission grid as the first child boundary.

If none of those conditions holds, keep the current parent and use replacement edits.
